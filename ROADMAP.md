# Veridian Roadmap

## Phase 1 — Core Foundation (Completed)

- MIRA state verification
- Sentinel enforcement
- Real Diya integration
- Executor
- AFS
- End-to-end Veridian demo

## Phase 2 — Ecosystem Integration (Completed)

- LangChain adapter
- AutoGen adapter
- CrewAI adapter

## Phase 3 — Dependency Demonstrations (Completed)

Controlled external applications that demonstrate fail-closed dependency patterns.

- veridian-first-dependent
- veridian-compliance-reviewer
- veridian-contract-reviewer
- veridian-audit-evidence-verifier

These are valuable demonstrations of technical feasibility and cross-domain applicability, but they are not yet independent third-party adoption.

## Phase 4 — Technical and Strategic Packaging (Completed)

Technical documentation and strategic materials.

- README.md

- ROADMAP.md

## Phase 5 — Production Hardening (Next)

The highest-priority remaining phase before broad adoption.

- Comprehensive automated tests
- Canonical PASS and FAIL examples
- API and schema stabilization
- Threat model
- Security review
- Performance and reliability validation
- Installation and onboarding refinement

## Phase 6 — Enterprise Pilots

Independent real-world deployments that create genuine external dependency.

- Independent users
- Design partners
- Internal enterprise pilots
- Third-party integrations
- Real operational deployments

At this stage, external organizations depend on Veridian in production environments.

## Phase 7 — Strategic Outcomes

Long-term platform outcomes.

- Industry standardization
- Mandatory dependency
- Control plane position
- Enterprise value creation

## Strategic Path

Standard → Dependency → Mandatory → Control Plane → Enterprise Value
