Goal

BIL must not create synthetic records.

BIL records must be generated by:

Diya PASS
→ write Intent Record

MIRA PASS
→ write State Record

AFS PASS
→ write Commit Record

If any gate fails:

no downstream record exists.

Examples

Diya FAIL:
Intent Record only

MIRA FAIL:
Intent Record
State Record
No Commit Record

PASS:
Intent Record
State Record
Commit Record
